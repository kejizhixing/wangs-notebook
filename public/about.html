关于这个博客

Wang's Notebook 是我的个人博客，在这里我记录技术学习笔记、生活感悟和各种资源分享。 它既是我的知识管理工具，也是我与世界交流的窗口。

博客的名字 "Notebook"（笔记本）体现了我的理念——写作即思考。 每一篇文章都是一次思考的沉淀，不求完美，但求真诚。

内容方向

这里的内容主要分为三类：

  • 技术笔记 —— AI、前后端开发、系统架构、工具推荐等
  • 生活随笔 —— 读书感悟、旅行记录、日常思考
  • 资源分享 —— 精选开发工具、学习资料、设计素材

技术栈

这个博客完全由我自己设计和开发，使用了以下技术：

  • 前端 —— 原生 HTML + CSS + JavaScript，零框架依赖
  • 后端 —— Cloudflare Pages Functions (Workers)
  • 数据库 —— Cloudflare D1 (Serverless SQLite)
  • 部署 —— Cloudflare Pages，全球 CDN 加速
  • 设计 —— 极简现代风格，支持暗色模式
